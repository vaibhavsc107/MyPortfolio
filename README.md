## 🚀 Tech Stack

* **Frontend Framework:** React.js (Vite)
* **Styling & Design:** Tailwind CSS
* **Icons & UI Assets:** Lucide / Custom Responsive Layouts
* **Deployment:** Vercel

---

## 📁 Portfolio Structure

The portfolio is structured around modular, reusable React components to maintain clean and scalable code:

* `src/components/Navbar.jsx`: Sticky responsive navigation bar with smooth section scrolling and a mobile drawer menu.
* `src/components/Hero.jsx`: Introduction section highlighting professional titles, a custom portrait display, and quick action buttons.
* `src/components/Projects.jsx`: Interactive grid showcasing core production-ready projects categorized by tech stack.
* `src/components/Skills.jsx`: Categorized technical proficiency matrix spanning languages, backend frameworks, databases, and tooling.
* `src/components/Footer.jsx`: Contact links, professional social profiles, and copyright tracking.

## 💻 Featured Projects Displayed

1. **Enterprise Inventory & Supply Chain Hub**
   * *Stack:* Java 17, Spring Boot, Spring Data JPA, MySQL, Docker
   * *Focus:* Robust backend architecture featuring Role-Based Access Control (RBAC), JWT security, global exception handling, and full containerization.
2. **Full-Stack Attendance Tracking System**
   * *Stack:* React.js, Node.js, Express.js, MongoDB, Tailwind CSS
   * *Focus:* End-to-end management platform featuring time-gated editing restrictions, server-side validation, and automated PDF report generation.
3. **Cricket Second-Innings Win Probability Predictor**
   * *Stack:* React.js, Tailwind CSS, Python, Machine Learning (Logistic Regression)
   * *Focus:* Interactive data visualization dashboard simulating live match conditions and calculating win probabilities.
